# 卡片数据 schema（cards_data_*.py）

`assets/cards_data_template.py` 是填空骨架（含错题 / 巩固两示例、字段中文注释）。

## CHECKS（错误归因五项，顺序固定）
```python
CHECKS = ["知识没掌握", "方法没想到", "思维不完整", "计算失误", "审题问题"]
```
`checked` 存 CHECKS 的下标列表，可多选（如 `[1, 2]`）。

## 每张卡字段
| 字段 | 说明 |
|------|------|
| no | 卡序号（从 1 递增） |
| title | 题目标题（简短，如「匀变速直线运动」） |
| page | 原扫描件 / 照片页码（整数或文件名） |
| kind | `"错题"` 或 `"巩固"` |
| origin | 题目来源（如「扫描全能王 2026-07-25 14.01.pdf P3」） |
| mark | **可选**，本题的选取方式：`"荧光笔圈出"` / `"框选"` / `"拍摄"` / `"清单"`。仅用于溯源展示，不填也可。 |
| ability | 考查能力项（一句话） |
| one | 正确思路 / 标准解法（可含 LaTeX，用 `<bs>` 占位反斜杠） |
| mistake | 错在哪（错题必填；巩固卡可留空字符串） |
| action | 怎么避免再错（防错动作） |
| tags | 标签列表，每项 `(类别, 内容)`，如 `("知识点", "牛顿第二定律")` |
| checked | CHECKS 下标列表，如 `[1, 2]` |

> **无效框选不生成卡片**：若学生框 / 圈 / 拍出的区域不含真实错题（空白、页眉页脚、老师批注、已订正例题等），按 `references/workflow.md` 的「无效框选处置」跳过，**不要**写进 CARDS；只在报告/台账记一笔「无效选取 N 处」。

## 示例（错题）
```python
{
    "no": 1, "title": "合力范围", "page": 3, "kind": "错题",
    "origin": "扫描全能王 2026-07-25 14.01.pdf P3",
    "ability": "受力分析中的合力范围估算",
    "one": r"合力满足 <bs>(|F_1-F_2|<bs>leq F_{<bs>text{合}}<bs>leq F_1+F_2<bs>)，代入 F_合=8N、F1=5N 得 F2∈[3,13]N。",
    "mistake": "直接取 F2=8N，忽略合力范围。",
    "action": "见「两力合成」先写不等式范围再代入。",
    "tags": [("知识点", "力的合成"), ("方法", "不等式范围")],
    "checked": [1, 2],
}
```

## 示例（巩固卡）
```python
{
    "no": 2, "title": "已订正例题", "page": 3, "kind": "巩固",
    "origin": "扫描全能王 2026-07-25 14.01.pdf P3（蓝笔例题）",
    "ability": "标准模型回顾",
    "one": r"例题：<bs>(F=ma<bs>) 直接代入。",
    "mistake": "",            # 巩固卡留空，生成器显示「原无实际错误」
    "action": "作为模板记忆。",
    "tags": [("知识点", "牛顿第二定律")],
    "checked": [],
}
```
