# 7 步诊断报告结构（错题诊断报告.md）

报告用 Markdown，标题含学生姓名与科目。建议章节：

1. **错题全景**：共 N 页 / 张照片、学生选取 M 道（荧光笔圈 / 框选 / 拍摄，任选其一），其中真实错题 X 道、巩固 K 道；若有「无效选取」也在此说明（如「框出 2 处空白已跳过」）；一句话概览。
2. **能力画像**：本次考查的能力项清单与强弱判断。
3. **错误归因**：按 CHECKS 五项统计数量（知识没掌握 / 方法没想到 / 思维不完整 / 计算失误 / 审题问题），指出主因。
4. **知识漏洞**：薄弱知识点列表（对应卡片 tags）。
5. **方法短板**：缺失的解题方法 / 思维模型。
6. **提升计划**：7 天可执行的微行动 + 4 周进阶安排。
7. **一句话提醒**：给学生的核心提醒。
+ **卡索引表**：卡号 / 标题 / 页码 / 类型 / 归因，便于回看。
